# 方块翻转

[English](README.md) · [项目首页](../../../../README_zh.md)

> Wuji Hand 手内方块翻转：基于 mjlab 和 PPO 训练策略，支持Wuji Hand 1 和 Wuji Hand 2 右手。手掌朝上，将方块旋转到指定目标姿态并保持，通过相机观测在真机上闭环执行。

[硬件搭建](docs/setup_zh.md) · [训练](docs/train_zh.md) · [部署](docs/deploy_zh.md)
